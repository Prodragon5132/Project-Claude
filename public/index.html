Questions people actually ask

Is my text really never uploaded?

Yes, and you do not have to take our word for it. Open your browser's developer tools, go to the Network tab, and use the tool. You will see the page load and then nothing. The page is served with a Content Security Policy of connect-src 'self', which means the browser itself refuses to let it contact any other host — that is enforced by your browser, not by our good intentions.

What happens if it misses something?

The Review tab shows you the original with every match highlighted, so you can see what was caught before you copy anything. Matches that relied on context rather than a checksum are flagged for a second look. No redaction tool is a substitute for reading the document, and this one is built to make that read fast rather than to pretend it is unnecessary.

Won't redacting break the model's answer?

Tokens keep the structure, so the model still knows two people are involved and which is which. If you would rather the text read naturally, Realistic-name mode substitutes plausible fictional names instead — drawn only from reserved ranges, so a pseudonymised document can never accidentally name a real person's real account.

Does this make us GDPR or HIPAA compliant?

No tool can do that on its own, and anyone claiming otherwise is selling you something. What SafePaste does is remove the identifiers from a document before you share it, and keep the mapping local. That is a control you can point at in a DPIA, not a certification. Talk to whoever owns compliance where you work.

Is there a subscription?

No. One payment, one licence key, yours permanently, updates included. If a future version is a major rewrite we may charge for that separately, but the version you bought keeps working forever — it is a static page that runs offline.

What if it doesn't work for me?

Email within 30 days and you get your money back, no argument and no form to fill in. The free tier exists so you can find that out before you pay, but the guarantee is there anyway.

Can we run it on our own infrastructure?

Yes — that is what the Business licence covers. It is a static site with no backend, so hosting it internally is a matter of copying a directory onto a web server. Air-gapped networks included.

Which languages does it handle?

Structured identifiers — cards, IBANs, IPs, keys, national ID numbers — are language-independent and work everywhere. Person and address detection is tuned for English-language documents today. Text in any script passes through untouched and round-trips exactly.
